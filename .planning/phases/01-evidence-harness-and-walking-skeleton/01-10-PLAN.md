## Phase Goal (user story)

**As a** developer, **I want to** run one command that builds the core and enforces the rights and determinism boundaries, **so that** I have proof that a skeleton machine is repeatable and refuses bad input without side effects.

<objective>
Give every fixture a validated identity (FND-03), and build cc65 from the verified pin with wall time and a reproducible linked probe as evidence (FND-09). The cc65 recipe is two sequential make invocations (`make bin`, then `make lib TARGETS=lynx`), per CONTEXT "Corrections from research" (F1: the single invocation races).

Purpose: guest-side tooling and fixtures get an identity and provenance before Phase 3 starts building original diagnostics with cc65.
Output: `check-manifests.sh`, two fixture manifests, the `cc65` and `probe` steps in `check.sh`, the probe fixture and `toolchain.probe`.
</objective>

## Flagged assumptions (spec-less probe)

- FND-09 `unclassified` (status unresolved): covered by the truths on the two-step build, wall time, tool hashes and probe hash. Two assumptions stay open. First, the probe `.lnx` is byte-identical on Linux gcc and macOS clang hosts (RESEARCH measured this on a scratch probe; the CI run in plan 01-13 confirms it for the committed probe). Second, GitHub commit-archive bytes stay stable; if a hash drifts, `fetch-pin.sh` prints the git-clone fallback identity instead of passing.
