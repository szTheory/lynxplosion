## Phase Goal (user story)

**As a** developer, **I want to** run one command that builds the core and enforces the rights and determinism boundaries, **so that** I have proof that a skeleton machine is repeatable and refuses bad input without side effects.

<objective>
Complete the Walking Skeleton's second half: the headless runner drives the public API and writes a real artifact bundle, and two fresh runner processes produce identical digests (DET-01) with a complete run manifest (DET-04). The runner's CLI contract, including the fixed-0x00 RAM power-on default, is tested.

Purpose: the host-surface layer (runner, bundle, evidence files) is proven end to end before the determinism gates in plan 01-08 build on it.
Output: `runner/`, the `lynx-run` executable, the skeleton fixture, `det.two_runs` and `runner.cli`.
</objective>

   - `bundle_write` creates the files in `dir`, which must already exist; `main` creates it.
   - `obs.ram.hex`: 65536 RAM bytes read through `lynx_read_memory`, lowercase hex, 32 bytes per line.
   - `obs.regs.hex`: 6 registers, each serialized as u32 little-endian.
   - `obs.time.hex`: `guest_ticks` u64 LE, `ticks_consumed` u64 LE, `stop` u32 LE.
   - `run.manifest`: `key = value` lines in this fixed order: `profile = none`, `startup_tier = A`, `content_sha256 = <64 hex from lynx_get_identity>`, `content_load_addr = 0x<4 hex>`, `input_digest = e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855` (SHA-256 of the empty input timeline), `tick_budget = <decimal u64>`, `ticks_consumed = <decimal u64>`, `stop_reason = budget|frame|watch|halt`, `core_build = <lynx_build_id()>`, `ram_policy = zero|splitmix64`, `ram_seed = 0x<16 lowercase hex>`, `evidence_tier = R`.
   - `digests.txt`: one `name sha256hex` line per file above, where the hash is of the canonical bytes for `obs.*` (not of the hex text) and of the file bytes for `run.manifest`. Lines are sorted by byte comparison inside the runner.

   - Exit codes: 0 success; 1 runtime or refusal error with a `lynx-run: <reason>` message on stderr; 2 usage with a `usage:` line on stderr.
   - Builds the config with `lynx_config_default` and applies `--ram-policy` / `--ram-seed` only when given (CONTEXT: fixed-0x00 is the runner CLI default).
   - Parses `--ticks` as a decimal `uint64_t` over the full range (`0` to `18446744073709551615`); anything else, including overflow, is a usage error.
   - Creates the `--out` directory with POSIX `mkdir` (an existing directory is reused). `CMAKE_C_EXTENSIONS OFF` hides POSIX declarations, so define `_POSIX_C_SOURCE 200809L` for the runner targets only (host side; never in `core/`).
   - Allocates the instance with `malloc` sized by `lynx_machine_size()` (`malloc` alignment covers `max_align_t`; assert it against `lynx_machine_align()`), and frees it before exit (LSan runs on Linux CI).
