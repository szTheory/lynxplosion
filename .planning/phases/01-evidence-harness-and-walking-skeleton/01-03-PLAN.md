## Phase Goal (user story)

**As a** developer, **I want to** run one command that builds the core and enforces the rights and determinism boundaries, **so that** I have proof that a skeleton machine is repeatable and refuses bad input without side effects.

<objective>
Enforce the determinism boundary of the core (FND-05) with two layers, each with a negative control:
- (a) a source scan: include allowlist plus floating-point scan;
- (b) a link-surface scan: `nm` of an uninstrumented twin library for undefined symbols, writable data and public-name equality.
Add a header self-containment test.

Purpose: from this plan on, any core code that reaches for a clock, file, thread, allocator, mutable global or floating point fails `scripts/check.sh`. The API work in plans 04 and 05 is held to the boundary as it is written.
Output: the `lynx_core_plain` target, three scan scripts, two committed violation fixtures, a header test and eleven inventory rows.
</objective>
