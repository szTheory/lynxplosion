## Phase Goal (user story)

**As a** developer, **I want to** run one command that builds the core and enforces the rights and determinism boundaries, **so that** I have proof that a skeleton machine is repeatable and refuses bad input without side effects.

<objective>
Make the test inventory exact (FND-06) and build the negative-control harness that every later gate reuses. The registered tests must equal `fast.txt` at configure time. Every listed test must have run exactly once in the JUnit output. Skips are honest only when declared. No test may self-skip. Each rule is proven by a self-test that feeds it a built fault. Per CONTEXT "Corrections from research", the declared set is checked at configure time against registration and the executed set through the JUnit step, in place of parsing `ctest -N`.

Purpose: a missing, extra or silently skipped test can never make the check green. This expands the tracer's check command with its first gate.
Output: shared `expect_fail.cmake`, the inventory and JUnit checkers, the `junit` step in `scripts/check.sh`, and four new inventory rows.
</objective>
