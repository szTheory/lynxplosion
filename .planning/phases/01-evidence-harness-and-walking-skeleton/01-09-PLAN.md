## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub archive download → build tree | Third-party source bytes enter the build |
| build tree cache → later check runs | A stamped extraction is reused |
| tests → network | A test that reaches the network would make the gate flaky and leak requests |
