## Phase Goal (user story)

**As a** developer, **I want to** run one command that builds the core and enforces the rights and determinism boundaries, **so that** I have proof that a skeleton machine is repeatable and refuses bad input without side effects.

(Restated from the ROADMAP Phase 1 goal sentence without adding scope. The ROADMAP goal line itself is not in user-story form.)

<objective>
Build the Walking Skeleton tracer. One command (`scripts/check.sh`) builds `lynx_core` with CMake. One C test creates an instance in caller memory, loads the provisional image, advances and inspects it. The runner writes an artifact bundle whose digests are equal across two fresh runs. GitHub Actions runs the same command on the public repository.

Purpose: prove every layer (driver script, CMake presets, core, public API, test, runner, bundle, CI) end to end before any gate or API expansion. Every later plan builds out from this slice.
Output: the skeleton files listed in frontmatter, `SKELETON.md` decisions realised in code, and the first green CI run.

On accept: call `lynx__power_on`, copy the bytes, set `pc = load_addr`, set `has_content = 1` with `content_addr` and `content_len`, and store the SHA-256 of the bytes (computed in the core, RESEARCH F4).
