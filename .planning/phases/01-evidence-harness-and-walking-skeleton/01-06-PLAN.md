## Phase Goal (user story)

**As a** developer, **I want to** run one command that builds the core and enforces the rights and determinism boundaries, **so that** I have proof that a skeleton machine is repeatable and refuses bad input without side effects.

<objective>
Complete the determinism gates (DET-01, DET-02, DET-04):
- in-process two-instance equality;
- a committed golden observation digest that proves compiler independence (Apple clang locally, gcc on CI);
- sensitivity controls against vacuous equality;
- a strict validator for `run.manifest` that also serves fixture manifests and claims later.
Push and confirm the golden on the CI runner.

Purpose: repeatability claims rest on non-vacuous, host-free, compiler-independent digests.
Output: the `det.*` tests, `tests/golden/skeleton.digest`, `scripts/validate-kv.sh`, and a CI run proving the golden on Linux gcc.
</objective>
